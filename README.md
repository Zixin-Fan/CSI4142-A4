# CSI4142 Assignment 4 - Unsupervised Learning

## Project Overview
This project explores clustering methods and recommendation systems using a real-world dataset. The goal is to experiment with similarity measures, clustering algorithms, content-based recommendation, and collaborative filtering.

## Dataset
We use "The Movies Dataset" from Kaggle:
https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset

Two main files are used:
- movies_metadata.csv (for similarity, clustering, and content-based recommendation)
- ratings_small.csv (for collaborative filtering)
